# Student Pass/Fail Analysis

## Project Description

This project analyzes student academic performance to identify the factors that may influence whether a student passes or fails.

The analysis was performed using Python and Google Colab.

## Dataset

The dataset contains student-related information such as:

- Study Hours
- Attendance
- Assignment Scores
- Exam Scores
- Pass/Fail Result

## 11 Steps Performed

1. Load and inspect the dataset
2. Find rows, columns, and check data types
3. Find missing values and duplicate rows
4. Identify invalid values
5. Check outliers using boxplots
6. Plot study-hours distribution and Pass vs Fail
7. Analyze study hours vs Pass/Fail and attendance vs Pass/Fail
8. Create correlation matrix/heatmap
9. Remove duplicates, fix invalid values, and handle missing values
10. Create new features
11. Separate X and y

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Feature Engineering

Two new features were created:

- Study Hour Category
- Attendance Category

## Target Variable

The target variable is:

**Pass/Fail**

## Conclusion

The analysis helps understand the relationship between study habits, attendance, academic performance, and student Pass/Fail status.
